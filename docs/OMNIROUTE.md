# OmniRoute

## Decision

Deferred. Normal Codex remains independent and untouched.

OmniRoute research found multiple active GitHub repositories and forks, not one clearly authoritative vendor source. Candidate documentation describes `npm install -g omniroute` and Codex launcher commands, but routing still needs model-provider credentials or accounts. No package, service, config, or provider was added.

Profiles remain conceptual:

- `CHEAP`: simple search, cleanup, repetitive edits; provider required.
- `NORMAL`: direct Codex default.
- `CRITICAL`: direct Codex only for auth, payments, migrations, finance, security, and destructive work.

Current state: `ROUTER NOT INSTALLED`; `PROVIDER REQUIRED`; `SOURCE AMBIGUOUS`. Do not route normal Codex through localhost until source, provider, trust boundary, rollback, and independent normal-Codex test are approved. Direct Codex remains default.
