# AGEX 2.4.0 (pre-release)

AGEX 2.4 turns "go install this yourself, then come back" into one button. **Install & Connect** now downloads, installs, configures, connects and tests a reviewed connection, including the runtime it needs and the Autodesk AI Bridge for Revit and AutoCAD.

## Platform testing: read this first

| Platform | Status |
| --- | --- |
| Windows x64 | **Runtime-tested** on a real machine: Node.js and uv installed by AGEX with the system copies hidden, then Playwright (browser), Context7 (npm), Windows-MCP (PyPI with uv), Exa (hosted) and Firecrawl (needs a key) connected through the desktop wizard; Update tested on Context7; the Autodesk AI Bridge installed from the prebuilt package, with its host answering the MCP handshake (99 tools). |
| Windows ARM64 | Built on CI. **The desktop app has not been run on ARM64 hardware.** The Autodesk AI Bridge package is x64 only. |
| macOS | Built and ad-hoc signed on CI. **Not run on a real Mac.** |
| Linux | Built on CI. **The desktop app has not been run on a Linux desktop.** |

Revit and AutoCAD were **not** seen connected live: Revit is not installed on the test machine, and its AutoCAD 2027 fails to start on its own (also without the bridge plug-in). The per-program status comes from the bridge host's own `autodesk_list_instances` tool once a program is open.

Packages are **not code-signed** and not notarized: expect a SmartScreen warning on Windows and a one-time "Open anyway" on macOS (see [INSTALL.md](https://github.com/Abdullah-Dawoud/Agex/blob/main/docs/INSTALL.md)).

## What is new

- **Install & Connect does everything it safely can**: reviewed npm and PyPI MCP servers are installed at their pinned version into AGEX's own folder, started from there and removed on Disconnect. Failures roll back.
- **Install dependency**: missing Node.js or uv is installed from the official download, checked against the published SHA-256, for your user only and without changing your system PATH. The connection continues right after.
- **Update** appears on connected tools when a newer pinned version is available.
- **Autodesk AI Bridge, prebuilt**: `autodesk-ai-bridge-win-x64.zip` is part of this release. Install & Connect on Revit or AutoCAD installs the host, the Revit 2025-2027 add-ins and the AutoCAD 2025+ plug-in for your user, configures the connection, tests it and shows each program's state. Nothing to compile; no Autodesk files are shipped.
- **Fixed**: wizard dialogs opened right after another dialog could not be closed; npm install scripts could pick a different Node.js.

## Install

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.ps1 -OutFile "$env:TEMP\agex-install.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\agex-install.ps1"
```

macOS / Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.sh | sh
```

AGEX 2.x users can also update from **Settings > Updates**.
