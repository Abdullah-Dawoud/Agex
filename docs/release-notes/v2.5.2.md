# AGEX 2.5.2 (pre-release)

Connected MCP resources, including current documents and resource-only connections, now reach enabled agents through AGEX. A connection test reads a listed resource before reporting Connected. Selected skills persist across messages. Agent process failures trigger a bounded health check before the next request.

The Workspace panel is available throughout the app. Separate project windows keep independent conversations, drafts, agent and model choices, and skills. The request composer and project settings expose model choices, including OmniRoute Auto through AGEX Models. Hermes has a one-shot adapter; Kilo, Goose and Crush appear as detected tools until AGEX has an adapter for them.

Windows tests and the Release build passed. CI builds and smoke-tests Windows, macOS and Linux packages. Live sign-in and model use need the user's provider accounts and were not exercised by the automated tests. Desktop GUI behavior on macOS and Linux needs hands-on testing there.

Packages remain unsigned unless release signing secrets are configured.
