# AGEX 2.5.0 (pre-release)

AGEX 2.5 is a quality release: Home feels like a chat app, the workspace appears only when there is something to show, simple messages stay simple, and "Connected" now means an agent really used the connection.

## Platform testing: read this first

| Platform | Status |
| --- | --- |
| Windows x64 | **Runtime-tested** on a real machine with real agents: "hi" with and without a project and with a Team active; a failing Antigravity replaced automatically by Codex; a bug fix with its change summary and undo; a real browser task (Codex with Playwright) and a real command, each shown in the workspace; skills added and removed per request; Playwright tested with Codex through **Test with agent**. Checked at 1366 x 768, 1600 x 900 and 1920 x 1080 at 125% scaling, in dark, light and high contrast. |
| Windows ARM64 | Built on CI. **The desktop app has not been run on ARM64 hardware.** |
| macOS | Built and ad-hoc signed on CI. **Not run on a real Mac.** |
| Linux | Built on CI. **The desktop app has not been run on a Linux desktop.** |

Packages are **not code-signed** and not notarized: expect a SmartScreen warning on Windows and a one-time "Open anyway" on macOS (see [INSTALL.md](https://github.com/Abdullah-Dawoud/Agex/blob/main/docs/INSTALL.md)).

## What is new

- **A calm Home**: the conversation first, a one-line composer with **+** for everything else, and chips only when they matter.
- **A workspace that follows the work**: Changes, Browser and Terminal appear on a slim rail when the agents produce them; open the panel compact or wide, or let it slide over the chat on small screens.
- **Simple chat stays simple**: no planning, no project scan, no skills or tools for "hi". If the first agent fails, another ready agent answers.
- **Skills follow the task**: Teams recommend, you decide. Add any installed skill or remove a suggested one for a request.
- **Connected means usable**: **Test with agent** proves an agent receives a connection and can call a read-only tool; cards say which agents can use each connection.
- **No project needed** for chat, questions and web or browser tasks.
- **Shorter setup**: four steps, in plain words.

## Install

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.ps1 -OutFile "$env:TEMP\agex-install.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\agex-install.ps1"
```

macOS / Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.sh | sh
```

AGEX 2.x users can also update from **Settings > Updates**. Settings move to schema 6: the workspace panel starts collapsed once.
