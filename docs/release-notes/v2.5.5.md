# AGEX 2.5.5 (pre-release)

The Autodesk connection dialog now watches for AutoCAD or Revit and an open document after installation. When an application was already running during installation, AGEX explains that it must be restarted to load the new add-in. A stopped application no longer appears connected based on an earlier bridge response.

The bridge host and plug-ins retain their pairing across application restarts and reconnect automatically. AGEX confirms a document and a read-only agent tool call before reporting the integration ready. Automated bridge tests and the AGEX Release test suite passed on Windows. This machine has no usable Autodesk installation, so AutoCAD and Revit runtime behavior was not exercised locally. CI builds the prerelease packages on Windows, macOS and Linux. Packages are signed only when release signing secrets are configured.
