# AGEX 2.5.3 (pre-release)

Connection cards put the real AGEX connection first. A website visit is labelled as separate from connecting. CLI sign-in opens in context, checks the account, and tests access with an enabled agent before reporting Connected. Unfinished background setup reports Needs attention until verification completes.

Home shows live task, agent, tool and change activity, and brings questions into view. The Workspace panel shows a compact live plan. Agent Room shows task dependencies and progress in a scrollable graph.

The Agents page shows AGEX-measured token use for current, daily and weekly activity across agents. Provider quota appears only when the provider reports it. The obsolete Efficiency control and its request effects are removed; older settings migrate automatically.

Automated tests and Release builds cover the local flows. Provider-specific login pages and desktop GUI behavior on other operating systems still require hands-on checks with those accounts and machines. Packages remain unsigned unless release signing secrets are configured.
