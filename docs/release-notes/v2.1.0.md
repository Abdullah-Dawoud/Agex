# AGEX 2.1.0 (pre-release)

AGEX 2.1 turns the agent launcher into a workspace: pick the kind of work, attach files, watch the team in a live side panel, and preview what it builds without leaving AGEX.

## Platform testing: read this first

| Platform | Status |
| --- | --- |
| Windows x64 | **Runtime-tested** on a real machine: desktop app, installer, embedded web preview (WebView2), live screen view, skill install dialogs, and real Codex, Antigravity, Ollama and OpenCode model discovery. |
| Windows ARM64 | Built on CI. **The desktop app has not been run on ARM64 hardware.** |
| macOS | Built and ad-hoc signed on CI. **Not run on a real Mac.** The web preview uses WKWebView and the live screen asks for the Screen Recording permission. |
| Linux | Built on CI. **The desktop app has not been run on a Linux desktop.** The web preview needs WebKitGTK (`libwebkit2gtk-4.1`); the live screen is not available on Linux yet. |

Packages are **not code-signed** and not notarized: expect a SmartScreen warning on Windows and a one-time "Open anyway" on macOS (see [INSTALL.md](https://github.com/Abdullah-Dawoud/Agex/blob/main/docs/INSTALL.md)).

## What is new

- **Model picker from the agents themselves**: Codex, Antigravity, Ollama, OpenCode, Claude Code and Gemini CLI list their real models with facts such as local/cloud, reasoning, vision and context. Auto is the default. Custom model IDs are under Advanced.
- **OpenCode** adapter (beta), including its free and local models.
- **Workspace panel**: Activity, Files, Preview (web pages and local dev servers inside AGEX, images, text, code), Diff and Computer (live screenshots while the team works, Pause, Resume, Take control, Stop).
- **Attachments**: attach, drop or paste images, PDFs, Office files, text and code, zip archives and videos. AGEX shows where each file goes before sending.
- **Teams built around jobs**: 11 teams, among them Software Builder, Research Lab, Architecture & BIM, Marketing & Growth, Computer Operator and Job Search. Each shows which tools are ready and has a setup checklist.
- **Routing & Providers** for Codex: Ollama or LM Studio on this computer, OmniRoute, OpenRouter or your own endpoint.
- **Efficiency modes**: Maximum quality, Balanced, Save tokens and Local-first. Save tokens made the leader's prompt 69% shorter in AGEX's test.
- **Skills**: 56 entries, with LOCAL / FREE / FREE TIER / PAID / API KEY REQUIRED labels and a Cost filter. New: Repomix, Serena and Windows-MCP.
- **Other tools** found on your computer now have actions: open your project in an editor, set a preferred editor, learn more, request an integration.
- Fix: agents installed in folders with spaces (for example under nvm) now start.

## Install

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.ps1 -OutFile "$env:TEMP\agex-install.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\agex-install.ps1"
```

macOS / Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.sh | sh
```

AGEX 2.0.0 users can also update from **Settings > Updates**.
