# AGEX 2.2.0 (pre-release)

AGEX 2.2 lets you tell it what kind of work you want to do. It then prepares the team, finds the tools you already have, and shows what else you can connect.

## Platform testing: read this first

| Platform | Status |
| --- | --- |
| Windows x64 | **Runtime-tested** on a real machine: Connections, MCP discovery, chat-first Home, skill selection, Changes and diffs, Teams setup, in dark, light and high contrast at 1366, 1600 and 1920 px. |
| Windows ARM64 | Built on CI. **The desktop app has not been run on ARM64 hardware.** |
| macOS | Built and ad-hoc signed on CI. **Not run on a real Mac.** |
| Linux | Built on CI. **The desktop app has not been run on a Linux desktop.** |

Packages are **not code-signed** and not notarized: expect a SmartScreen warning on Windows and a one-time "Open anyway" on macOS (see [INSTALL.md](https://github.com/Abdullah-Dawoud/Agex/blob/main/docs/INSTALL.md)).

## What is new

- **Connections**: one page for everything agents can use: programs on this computer, web services, MCP servers and agents' tools. Each item shows a clear state and its next step: Connect, Download, Sign in, Add key, Test, Disconnect, or Open project. Your team's connections come first.
- **Existing MCP connections found automatically**: servers you already set up in other AI tools (Claude Code, Claude Desktop, Codex, Gemini CLI, Antigravity, VS Code, Cursor, Windsurf, OpenCode) can be imported or left as they are. Keys stay in the original file unless you choose to copy them. When AGEX has a reviewed version of a server, it offers that instead.
- **Add connection**: search programs and services. On request, AGEX also searches the public MCP Registry; those results are clearly marked as not reviewed.
- **Honest program detection**: covers Revit, AutoCAD, Navisworks, Bluebeam, SketchUp, Blender, Figma, browsers, Office, Obsidian, Docker, Git, GitHub CLI and more. AGEX says exactly how it can work with each program: MCP, command line, files only, opening projects, or not yet.
- **Chat-first Home**: the conversation fills the screen. Pick a team to see your tools and example requests. The composer has compact Team, Skills, Efficiency and Agents menus.
- **Skills per request**: use Auto or choose skills for one request. Save profiles, pin skills to a team, or give a skill only to certain agents.
- **Changes**: every created, modified, deleted or renamed file, with lines added and removed. View changes as unified or side-by-side diffs (also without Git), and see changed files in a project tree. Each result shows a "Changes: N files +A -R" summary.
- **Smarter Teams**: each team lists the files it works with, the actions it always asks you about, and the paid tools it works alongside, based on O*NET research. Setup shows what is ready, what to set up and what is optional.
- **Smart tips**: optional suggestions such as the PDF skill for a PDF, web research for research questions, or Save tokens for large projects. You can dismiss any tip for good.
- Fix: the Autodesk AI Bridge connection now shows as connected.

## Install

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.ps1 -OutFile "$env:TEMP\agex-install.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\agex-install.ps1"
```

macOS / Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.sh | sh
```

AGEX 2.x users can also update from **Settings > Updates**.
