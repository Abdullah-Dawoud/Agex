# AGEX 2.0.0 (pre-release)

AGEX lets several AI coding agents work together on your projects: a leader agent plans, AGEX hands tasks to the agents you chose, checks what they did and shows every step.

## Platform testing: read this first

| Platform | Status |
| --- | --- |
| Windows x64 | **Runtime-tested** on a real machine: desktop app, installer and real Codex, Antigravity and Ollama requests. |
| Windows ARM64 | Built on CI; the `agex` command is smoke-tested on an ARM64 CI runner when one is available. **The desktop app has not been run on ARM64 hardware.** |
| macOS (Apple Silicon and Intel) | Built and ad-hoc signed on macOS CI; the test suite passes on macOS CI and the `agex` command is smoke-tested there. **Not yet run on a real Mac; the desktop app is untested on macOS.** |
| Linux (x64 and ARM64) | Built on Linux CI; the test suite passes on Linux CI and the `agex` command is smoke-tested there. **The desktop app has not been run on a Linux desktop.** |

Packages are **not code-signed** (no Windows certificate, no Apple Developer ID) and not notarized: expect a SmartScreen warning on Windows and a one-time "Open anyway" on macOS (see [INSTALL.md](https://github.com/Abdullah-Dawoud/Agex/blob/main/docs/INSTALL.md)). `SHA256SUMS.txt` is not signed yet; the installers check every package against it.

Help test on a Mac or Linux desktop: [docs/MAC_TEST.md](https://github.com/Abdullah-Dawoud/Agex/blob/main/docs/MAC_TEST.md), [docs/LINUX_TEST.md](https://github.com/Abdullah-Dawoud/Agex/blob/main/docs/LINUX_TEST.md).

## What is new

- **Cross-platform desktop app** (C#, .NET 10, Avalonia) replacing the Windows-only 1.x app; the `agex` command line for the same features.
- **Agent Room**: the messages agents actually exchange, with filters, search, copy, follow live and a task graph; never hidden reasoning.
- **Agents**: Codex CLI and Antigravity CLI (supported), Ollama local models (beta), Claude Code and Gemini CLI (beta, not yet run with signed-in accounts).
- **Automatic discovery** of installed agents, editors and tools, with honest statuses (Ready, Not installed, Sign-in required, Not working, …).
- **Skills Manager** with **19 curated skills** (14 instruction skills pinned to exact commits and checked by SHA-256, 5 MCP tools), one-click install, permissions and trust levels, custom skills.
- **Session history** with search, export, continue and retry; **Git snapshots with one-click undo** for every request that changes files; approval before changes.
- **Themes**: system, light, dark and high contrast; text size setting.
- **One-command install** for Windows, macOS and Linux with checksum verification; in-app updates.

## Install

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.ps1 -OutFile "$env:TEMP\agex-install.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\agex-install.ps1"
```

macOS / Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.sh | sh
```
