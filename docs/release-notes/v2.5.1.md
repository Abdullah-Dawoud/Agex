# AGEX 2.5.1 (pre-release)

This patch makes connected tools available through AGEX to enabled agents, including agents without native per-run MCP configuration. AGEX keeps tool sessions open across calls and asks before sensitive actions.

Connection sign-in now shows Waiting for sign-in in context, checks completion, returns focus, and updates status. CLI sign-in uses the provider's terminal and system browser. Web pages fall back to the system browser if the embedded browser cannot load them. Connection checks expire so old results do not stay Connected indefinitely.

Windows tests and Release build passed. CI builds and smoke-tests Windows, macOS, and Linux packages. Desktop sign-in with live accounts was not exercised for this patch; provider credentials are required for that check.

Packages remain unsigned unless release signing secrets are configured. macOS and Linux desktop behavior still needs testing on those systems.
