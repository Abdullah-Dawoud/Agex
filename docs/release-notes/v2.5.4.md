# AGEX 2.5.4 (pre-release)

Antigravity retries one process failure when no tool work has started. AGEX checks the executable before retrying and keeps project settings, selected skills, connections and conversation history. A failed agent test no longer labels the underlying connection broken.

AGEX validates MCP servers by their working tools or resources. Tool-only servers keep working when optional resource listing fails. The Autodesk bridge no longer advertises resources it does not implement. Bridge status distinguishes application installation, running state, plug-in connection and an open document, with short next steps.

Skills has Active and Available lists, search and advanced controls. Explicit skill choices stay selected across messages until changed.

While a request runs, Home shows a short progress line and live counts for changed files, commands, tools, tests and retries. Expand the details under the request to inspect the structured events AGEX receives. The final answer stays clean.

Automated tests cover agent and connection failure modes. Real Antigravity passed repeated simple requests and an AGEX gateway tool call on Windows. AutoCAD/Revit runtime integration could not be exercised without a running Autodesk application; CI builds and smoke-tests the packages on Windows, macOS and Linux. Packages remain unsigned unless release signing secrets are configured.
