# AGEX 2.3.0 (pre-release)

AGEX 2.3 behaves like a chat app first and an orchestration engine only when needed. Say "hi" and it replies. Ask a question and it answers without changing anything. Say "plan" and it plans. Say "build", or "open the game and play it", and the team works, using the right tools.

## Platform testing: read this first

| Platform | Status |
| --- | --- |
| Windows x64 | **Runtime-tested** on a real machine with real Codex runs: quick chat, project questions, plans, a build, and opening and playing a local web game in a real browser. Home, history, approvals, agent settings, usage and connection wizards checked at 1366, 1600 and 1920 px (125% scaling). |
| Windows ARM64 | Built on CI. **The desktop app has not been run on ARM64 hardware.** |
| macOS | Built and ad-hoc signed on CI. **Not run on a real Mac.** |
| Linux | Built on CI. **The desktop app has not been run on a Linux desktop.** |

Packages are **not code-signed** and not notarized: expect a SmartScreen warning on Windows and a one-time "Open anyway" on macOS (see [INSTALL.md](https://github.com/Abdullah-Dawoud/Agex/blob/main/docs/INSTALL.md)).

## What is new

- **Fast chat and modes**: Auto, Ask, Plan and Build in the composer. Greetings and questions no longer start the planning pipeline. On a real Codex run, "hi" went from 34k to 17k input tokens and a project question from 88k to 50k.
- **Home as a chat**: conversation list, projects, New chat, reopen and continue conversations. Answers are formatted.
- **The right tools, chosen automatically**: AGEX works out what a request needs and sends browser work to an agent with a real browser. It serves your project's pages on 127.0.0.1 so JavaScript modules load, and says exactly what is missing with a one-click fix.
- **Fixed**: MCP tools (including the browser) were refused inside Codex's non-interactive mode. They now work after AGEX's own approval.
- **Approval modes and permissions**: Ask every time, Smart approvals, Trust this session, and plain-language switches for what agents may do. Sensitive actions always ask.
- **Agent settings that match each agent**, for example reasoning effort only where the agent accepts it.
- **Usage**: Codex plan and 5-hour and weekly limits; tokens per request and per agent; totals for today, this week and this project.
- **One-click MCP connections** with a real connection test, and a step-by-step Autodesk bridge setup.

## Install

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.ps1 -OutFile "$env:TEMP\agex-install.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\agex-install.ps1"
```

macOS / Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/Abdullah-Dawoud/Agex/main/install/agex-install.sh | sh
```

AGEX 2.x users can also update from **Settings > Updates**.
